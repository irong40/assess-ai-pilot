       - Import types from `./agent-types.ts`
       - Import `createServiceClient` from `./supabase-client.ts`
       - Export `executeAgentTask(supabase, task, handler)`:
         a. Validate company_id exists in the companies table
         b. Validate delegation_depth < 3 (prevent infinite delegation loops)
         c. If task has source_agent, validate it is 'ciso_orchestrator' (hub-and-spoke per INFRA-08)
         d. Update agent_tasks.status to 'running', set started_at
         e. Execute the handler function in a try/catch
         f. On success with risk_level 'high': set status 'awaiting_approval', do NOT write output yet
         g. On success with risk_level 'low' or 'medium': set status 'completed', write output, set completed_at
         h. On error: set status 'failed', write error message, set completed_at
         i. After every outcome: call `log_audit_event` RPC with agent_type, action, reasoning_summary
         j. ALL database queries include `.eq('company_id', task.company_id)` -- non-negotiable
       - Export `delegateTask(supabase, fromTask, toAgentType, action, input)`:
         a. Validate fromTask.agent_type is 'ciso_orchestrator'
         b. Calculate new delegation_depth = fromTask.delegation_depth + 1
         c. Insert new agent_tasks row with parent_task_id = fromTask.id
         d. Send to pgmq via `supabase.schema('pgmq_public').rpc('send', ...)`

    3. Create `supabase/functions/agent-worker/index.ts`:
       - Deno.serve handler following existing Edge Function CORS pattern
       - Authenticate: Accept requests from pg_cron (body `{"source": "cron"}`) OR authenticated users with valid JWT
       - Read up to 5 messages from pgmq with 120-second visibility timeout: `supabase.schema('pgmq_public').rpc('read', { queue_name: 'agent_tasks', sleep_seconds: 120, n: 5 })`

       - On successful processing: delete message from pgmq via `supabase.schema('pgmq_public').rpc('delete', { queue_name: 'agent_tasks', msg_id: msg.msg_id })`
       - On failure: log error, message becomes visible again after vt expires (auto-retry)
       - Return JSON with processed count
       - Stay within 150-second Edge Function timeout (max 5 messages per invocation per research)
