<objective>
AppSec Engineer agent with dependency manifest scanning, configuration file review, vulnerability findings with fix suggestions, and security review reports.

Purpose: The AppSec agent parses uploaded dependency manifests (package.json, requirements.txt, pom.xml) as plain text, cross-references package-version pairs against the existing threat_intelligence CVE table, and reviews configuration files for security misconfigurations. No external SCA tools -- all analysis uses local data. Findings include fix suggestions and map to CMMC controls.

Output: AppSec Edge Function, Zod schemas, 5 domain tools (including manifest parser), appsec_findings migration, CISO delegateToAppSec extension, vitest-compatible Node mirrors, test suite.
</objective>
