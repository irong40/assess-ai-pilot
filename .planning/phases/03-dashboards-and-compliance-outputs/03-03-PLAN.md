```typescript
export type FindingStatus = 'MET' | 'NOT_MET' | 'NOT_APPLICABLE';
export type EvidenceMethod = 'examine' | 'interview' | 'test';
export interface GapAnalysisFinding {
  control_id: string; control_title: string; family_id: string; family_name: string;
  status: FindingStatus; failed_objectives: string[];
  evidence_gaps: Array<{ method: EvidenceMethod; description: string }>;
  remediation_options: Array<{ option_id: string; description: string; cost_tier: string; effort_tier: string; timeline_days: number; priority_rank: number }>;
}
export interface GapAnalysisReport {
  assessment_date: string; cmmc_level: number; sprs_score: number;
  total_controls: number; met_count: number; not_met_count: number;
  findings: GapAnalysisFinding[];
}
export interface AuditPackageSection {
  family_id: string; family_name: string;
  controls: Array<{ control_id: string; title: string; status: FindingStatus; implementation_statement: string; evidence_references: string[] }>;
}
```

From NOTEBOOKLM-CMMC-REFERENCE.md -- POA&M required fields:
1. Control Identifier (NIST 800-171 control ID)
2. Current State / Weakness (detailed description)
3. Risk/Impact Assessment (how weakness impacts CUI environment)
4. Remediation Action and Milestones (technical + procedural steps, trackable milestones)
5. Resources Required (funding, tools, personnel)
6. Owner / Responsibility (specific individual or role)
7. Scheduled Due Dates (realistic timelines)

POA&M critical rules:
- Minimum SPRS score of 80/110 to use POA&M
- MFA, FIPS encryption, IR, audit logging, SSP cannot be deferred
- 180-day remediation deadline

From NOTEBOOKLM-CMMC-REFERENCE.md -- SSP required structure:
- Organized by 14 NIST 800-171 control families
- Each control: implementation statement (specific, not generic), evidence references
- Cover page with company name, assessment date, CMMC level

Database tables available:
- gap_analysis_results: id, company_id, report (JSONB = GapAnalysisReport), created_at
- compliance_snapshots: sprs_score, family_scores, poam_eligible, critical_controls_met
- poam_entries: existing table with POA&M data
- controls: control_id, title, family, description (CMMC control reference data)
- document_embeddings: document_id, document_name (existing document storage)
- assessment-documents: existing Supabase storage bucket

Existing components:
- FileUpload component at src/components/FileUpload.tsx (handles file upload to Supabase storage)
- Use jspdf + jspdf-autotable for PDF generation (new dependency -- install in this plan)
