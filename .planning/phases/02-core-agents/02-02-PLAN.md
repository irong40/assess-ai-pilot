<objective>
Build the CISO Orchestrator agent -- the coordination layer that receives high-level compliance requests, delegates tasks to the GRC Analyst, tracks delegation status, synthesizes results into executive summaries, and escalates high-risk findings for human approval. Also build the frontend hooks and services for dispatching agent tasks and viewing the CISO task queue.

Purpose: The CISO Orchestrator completes the "minimum viable AI security team" by providing the coordination layer on top of the GRC Analyst. Users interact with the CISO (run assessment, get summary), the CISO delegates to specialists, and the user sees status and results.

Output: Working CISO Orchestrator Edge Function with delegation and synthesis tools, frontend useAgentTasks hook for task queue visibility, agentService for dispatching tasks from the client, and all supporting schemas and tests.
